# 📊 학습 대시보드

> [!note] Dataview 플러그인
> 아래 표는 **Dataview** 커뮤니티 플러그인이 있어야 자동으로 채워진다.
> (설정 → 커뮤니티 플러그인 → `Dataview` 설치 후 활성화)
> 플러그인이 없다면 맨 아래 **수동 체크리스트**를 쓰면 된다.

## 🔥 지금 듣는 중
```dataview
TABLE track AS 트랙, progress AS "진도(%)", started AS 시작일
FROM #claude-academy
WHERE type = "course" AND status = "in-progress"
SORT course-no ASC
```

## ⭐ 우선순위 9개 코스 현황
```dataview
TABLE track AS 트랙, level AS 난이도, duration AS 분량, status AS 상태
FROM #claude-academy
WHERE type = "course" AND contains(list(14,15,1,21,5,3,4,9,7), course-no)
SORT course-no ASC
```

## ✅ 완료한 코스
```dataview
TABLE finished AS 완료일, rating AS 평점, track AS 트랙
FROM #claude-academy
WHERE type = "course" AND status = "done"
SORT finished DESC
```

## 📚 전체 카탈로그
```dataview
TABLE WITHOUT ID
  link(file.link, string(course-no) + ". " + `title-ko`) AS 코스,
  track AS 트랙, level AS 난이도, duration AS 분량, status AS 상태
FROM #claude-academy
WHERE type = "course"
SORT course-no ASC
```

## 🧪 실습 기록
```dataview
TABLE date AS 날짜, result AS 결과, related-course AS 관련코스
FROM #claude-academy
WHERE type = "practice"
SORT date DESC
LIMIT 15
```

## 🔁 복습이 필요한 코스 (완료 후 7일 경과)
```dataview
TABLE finished AS 완료일, (date(today) - date(finished)).days AS "경과(일)"
FROM #claude-academy
WHERE type = "course" AND status = "done" AND date(finished) <= date(today) - dur(7 days)
SORT finished ASC
```

## 상태값 규칙
코스 노트의 `status` 필드에 다음 중 하나를 쓴다.

| 값 | 뜻 |
|---|---|
| `not-started` | 아직 시작 안 함 |
| `in-progress` | 듣는 중 |
| `done` | 완료 (+ `finished` 날짜 기입) |
| `skipped` | 내게 해당 없음 |
