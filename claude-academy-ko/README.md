# 클로드 아카데미 한국어 학습 볼트 (Obsidian)

Anthropic의 무료 학습 플랫폼 **Claude Academy** 커리큘럼을 한국어로 정리한 옵시디언 볼트입니다.

## 사용법

1. **옵시디언에서 열기**
   - 이 `claude-academy-ko` 폴더를 새 볼트로 열거나,
   - 기존 볼트 안에 폴더째 복사해 넣으면 됩니다.
2. **권장 플러그인**
   - `Dataview` — [[학습 대시보드]]의 진도 표가 자동으로 채워집니다. (없어도 수동 체크리스트로 사용 가능)
3. **시작점**: `00-홈/클로드 아카데미 MOC.md`

## 구조

```
claude-academy-ko/
├── 00-홈/           클로드 아카데미 MOC   ← 여기서 시작
├── 01-학습경로/     트랙 4개
├── 02-코스/         코스 노트 24개
├── 03-핵심개념/     개념 노트 12개
├── 04-템플릿/       레슨 노트 · 실습 기록 템플릿
└── 05-학습관리/     학습 대시보드 · 8주 학습 플랜 · 실무 적용 아이디어
```

## 출처

- 공식: <https://academy.claude.com> (전 과정 무료, 이메일만으로 수강)
- 한국어 커리큘럼: <https://academy.needslab.ai>
- 코스 카탈로그 정리 참고: <https://github.com/Amey-Thakur/CLAUDE-CERTIFICATIONS>

> 코스 목록·트랙 구성은 공식 영어 카탈로그(24개 코스) 기준입니다.
> 일부 코스의 분량은 한국어 커리큘럼 소개 자료 기준이며, `확인 필요`로 표시된 항목은
> 실제 수강하면서 채워 넣도록 비워 두었습니다.
> 개념 노트는 공개된 Anthropic 문서 지식을 바탕으로 정리한 것으로,
> 강의 내용과 다른 부분이 있으면 수강하며 직접 수정하세요.
