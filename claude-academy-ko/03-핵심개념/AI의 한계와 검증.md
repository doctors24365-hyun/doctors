# AI의 한계와 검증
> [!danger] 한 문장
> LLM은 **그럴듯한 다음 말**을 만드는 기계다. 진실을 조회하는 기계가 아니다.

---

## 구조적 한계 4가지
| 한계 | 무슨 일이 생기나 | 대응 |
|---|---|---|
| **환각** | 없는 사실·출처·수치를 자신 있게 지어냄 | 1차 출처 대조 |
| **지식 컷오프** | 학습 시점 이후를 모름 | 최신 정보는 검색/자료 제공 |
| **맥락 부재** | 우리 조직 사정을 모름 | 배경을 명시적으로 제공 |
| **동조 경향** | 사용자 주장에 끌려감 | 반대 근거를 따로 요구 |

---

## 검증 강도 정하기
결과가 틀렸을 때의 대가로 결정한다.

| 위험도 | 예시 | 검증 |
|---|---|---|
| 낮음 | 아이디어 발산, 문장 다듬기 | 읽어보고 넘어감 |
| 중간 | 내부 보고서, 코드 초안 | 실행·테스트·교차 확인 |
| **높음** | 의학 정보, 법규, 계약, 대외 공표 | **원문 출처 직접 확인, 전문가 검토** |

> [!warning] 개원가에서 특히
> - 진료 정보·약제·용량 → 반드시 1차 문헌/제품설명서 확인
> - 의료광고 문구 → 의료법·심의 기준 직접 대조
> - 환자 개인정보 → 애초에 입력하지 않는다

- "모르면 모른다고 답하라"를 명시
