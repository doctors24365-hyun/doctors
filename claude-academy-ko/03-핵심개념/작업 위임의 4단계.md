# 작업 위임의 4단계
> [!tip] 한 문장
> AI에게 일을 넘길 때도 **사람에게 일을 넘길 때와 같은 순서**를 밟는다.

---

## 1. 범위 확정
"무엇이 끝난 상태인가"를 먼저 정의한다. 이게 흐릿하면 결과도 흐릿하다.

## 2. 맥락 전달
- 배경 (왜 하는가)
- 제약 (하면 안 되는 것)
- 참고 자료 (기존 예시가 있으면 최강)

## 3. 중간 점검
긴 작업일수록 **끝까지 가기 전에** 한 번 본다.
- 계획을 먼저 받아본다 (Plan)
- 첫 산출물 하나만 받아 방향을 확인한다

## 4. 검수와 수용
- 형식 → 사실 → 판단 순으로 본다
- **책임은 넘어오지 않는다.** 최종 확인은 내 몫.

---

## Cowork / 서브에이전트에서
이 4단계가 그대로 태스크 루프가 된다.

| 단계 | Cowork에서 | Claude Code에서 |
|---|---|---|
| 범위 | 태스크 정의 | 프롬프트 + Plan 모드 |
| 맥락 | 파일·커넥터 연결 | CLAUDE.md + 파일 참조 |
| 점검 | 중간 산출물 확인 | 커밋 단위 리뷰 |
| 검수 | 결과 수용/반려 | 테스트 + 코드 리뷰 |
