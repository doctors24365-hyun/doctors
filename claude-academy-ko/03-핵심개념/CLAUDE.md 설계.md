# CLAUDE.md 설계
> [!tip] 한 문장
> 매 세션 반복해서 설명하던 프로젝트 규칙을 **파일 하나에 고정**시키는 장치.

Claude Code가 세션 시작 시 자동으로 읽는 파일. 프로젝트 루트에 둔다.

---

## 무엇을 적나
| 넣을 것 | 넣지 말 것 |
|---|---|
| 빌드/실행/테스트 명령 | 코드를 읽으면 아는 사실 |
| 프로젝트 구조 요약 | 장문의 아키텍처 에세이 |
| 코딩 컨벤션·금지사항 | 자주 바뀌는 TODO |
| 배포 절차 | 비밀키·토큰 (절대) |
| 자주 하는 실수 경고 | |

---

## 예시 (신사닥터스 업무관리 기준)
```markdown
# 신사닥터스 업무관리

## 구조
- `index.html` — 단일 파일 SPA. 스타일/스크립트 모두 인라인.
- 백엔드: Supabase (테이블 스키마는 `docs/schema.sql`)

## 규칙
- 단일 파일 구조를 유지할 것. 빌드 도구를 도입하지 말 것.
- CSS 변수는 `:root`에 정의된 팔레트만 사용.
- 환자 식별정보는 콘솔에 로그하지 않는다.

## 확인 방법
- 변경 후 브라우저에서 직접 열어 동작 확인.
```

---

## 관리 원칙
- **짧게 유지.** 길어지면 오히려 안 읽힌다. 한 화면 분량이 목표.
- **틀린 규칙은 즉시 고친다.** 낡은 CLAUDE.md는 없느니만 못하다.
- Claude가 같은 실수를 반복하면 → 그 교정을 여기에 한 줄 추가
