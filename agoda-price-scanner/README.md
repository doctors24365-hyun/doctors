# 아고다 최저가 스캐너 (크롬 확장프로그램)

같은 호텔·같은 날짜·같은 객실인데도 **어떤 링크로 들어가느냐에 따라 아고다 가격이 달라지는 것**을
자동으로 비교해 주는 크롬 확장프로그램입니다.

영상에서 손으로 하던 세 가지를 버튼 한 번으로 처리합니다.

| 영상에서 한 일 | 이 확장에서 |
|---|---|
| 크롬 설정 → 쿠키·사이트 데이터 삭제 후 가격 다시 보기 | 스캔 시작 시 아고다 쿠키·로컬 데이터를 자동 삭제 (체크박스로 끌 수 있음) |
| URL의 `cid=1833981`을 다른 번호로 바꿔 검색 | 등록된 CID 전부를 백그라운드 탭에서 열어 가격 수집 |
| '아고다 스캐너'에 링크 넣고 제일 싼 거 고르기 | 결과를 가격순으로 정렬해 최저가·절약 금액 표시, 그 링크로 바로 이동 |

## 설치

1. 이 폴더(`agoda-price-scanner/`)를 내려받습니다.
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드** 클릭 → 이 폴더 선택

웹스토어 등록 없이 쓰는 방식이라 크롬을 다시 켜도 그대로 유지됩니다.

## 사용법

1. 아고다에서 원하는 호텔·날짜·인원까지 고른 상태의 페이지를 엽니다.
2. 툴바의 확장 아이콘 클릭 → **현재 탭에서 가져오기**
3. **최저가 찾기** 클릭
4. 백그라운드(최소화된) 창에서 CID별 페이지가 차례로 열리고, 가격이 모이는 대로 표가 채워집니다.
5. 제일 싼 항목의 **이 가격으로 예약 페이지 열기**로 이동해 결제합니다.

> 날짜·인원이 링크에 포함돼 있어야 정확히 비교됩니다. 호텔 목록 페이지가 아니라
> **객실 가격이 보이는 상세 페이지** 링크를 넣으세요.

## 설정

- **스캔 전 아고다 쿠키·로컬 데이터 삭제** — 영상의 1번 방법. 이전 검색 이력이 붙은 가격 대신
  '처음 온 사용자' 가격을 받게 합니다. 켜면 아고다 로그인도 풀립니다.
- **스캔용 창 최소화** — 스캔 탭이 작업을 방해하지 않도록 별도 최소화 창에서 엽니다.
  결과가 계속 "가격 못 읽음"으로 나오면 이 옵션을 꺼 보세요. (최소화 창은 크롬이 렌더링을 늦출 수 있습니다.)
- **동시 탭 수** — 1~4. 높일수록 빠르지만 아고다 쪽에서 응답이 느려지거나 막힐 수 있어 기본값 2를 권합니다.
- **비교할 CID** — 한 줄에 하나씩. `번호<탭>메모` 형식이며 `#`으로 시작하는 줄은 주석입니다.
  빈 줄(번호 없음)은 `cid` 없는 기본 링크를 뜻합니다.
- **쿠키만 삭제** — 스캔 없이 아고다 쿠키만 지우고 싶을 때.

## 동작 원리

```
예약 링크  →  cid만 바꾼 URL 여러 개 생성 (tag·gclid 등 경쟁 파라미터는 제거)
          →  백그라운드 탭에서 하나씩 로드
          →  content.js가 실제 렌더링된 가격 엘리먼트를 읽음
          →  통화별로 정리해 최저가 선택
```

가격은 아고다가 화면에 그려 놓은 값을 그대로 읽습니다(비공개 API 호출 없음).
취소선 처리된 정가와 최종가가 함께 노출되므로 **같은 통화 중 가장 낮은 값**을 결제가로 봅니다.

## 알아 둘 점

- **CID는 영원하지 않습니다.** 기본 목록은 공개적으로 돌아다니는 값들이라 만료되거나 막힐 수 있습니다.
  유효하지 않은 CID는 그냥 기본가와 같은 값이 나오므로 손해는 없습니다. 새 코드를 알게 되면 목록에 추가하세요.
- **가격은 실시간으로 바뀝니다.** 스캔 결과와 결제 화면 금액이 다를 수 있으니
  **결제 직전 최종 금액·세금 포함 여부·취소 규정**을 반드시 확인하세요.
- CID에 따라 **취소 정책이나 세금 표기 방식이 다를 수 있습니다.** 금액만 보고 고르지 마세요.
- 아고다가 페이지 구조를 바꾸면 가격을 못 읽을 수 있습니다. 그럴 땐 `content.js`의
  `PRICE_SELECTORS`에 새 셀렉터를 추가하면 됩니다.
- 개인적인 가격 비교 용도로 만들었습니다. 동시 탭 수를 무리하게 올려 반복 조회하지 마세요.

## 파일 구조

```
agoda-price-scanner/
├── manifest.json   확장 설정 (Manifest V3)
├── background.js   스캔 오케스트레이터 — 쿠키 삭제, 탭 열기, 결과 취합
├── content.js      아고다 페이지에서 가격 읽기
├── cids.js         기본 CID 목록 · 기본 설정값 · 파싱 유틸
├── popup.html/css/js  사용자 화면
└── icons/          아이콘
```
